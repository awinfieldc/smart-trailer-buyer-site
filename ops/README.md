# Smart Trailer Buyer Operating Templates

These files support the public launch funnel. They are templates and operating notes only.

Do not store real names, emails, phone numbers, customer notes, form responses, or private lead data in this public website repo. Keep live lead data in the Google Form response sheet, a private CRM, or the private launch workspace.

## Files

- `email-follow-up-sequence.md` - first five emails after a checklist request.
- `lead-tracker-template.csv` - safe header template for tracking source and follow-up status.
- `posting-system.md` - repeatable short-form content system.
- `brand-and-social-checklist.md` - profile consistency and bio link setup.
- `analytics-and-search-setup.md` - Vercel Analytics, UTM, and Search Console checklist.
- `openmontage-content-plan.md` - how OpenMontage should fit the content workflow.
